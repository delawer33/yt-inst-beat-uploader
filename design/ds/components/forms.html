The Draft screen from Mockup 3b: .crumb head, .split-form with a .col-form beside a .col-preview, .fact-row lines and a .tag-input whose chips are buttons and whose .tag-entry takes the next tag. The preview column is --preview-w wide — its own token, not the side panel’s --panel-w, so the two can never drag each other. Shown here at the width the app ships.

A .seg that stands for a whole choice takes a .group-label and names itself with aria-labelledby: no single control carries that label, so a <label> would name nothing.

Native elements, themed states, no script. Inputs sit on --color-input, a step darker than the surface. Changes save on blur; there is no form-level Save.
